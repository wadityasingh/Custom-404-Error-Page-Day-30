# Custom 404 Error Page

A custom 404 error page designed to help visitors when they land on a page that does not exist. Instead of showing a plain error message, the page uses a friendly message, a creative map-inspired illustration, and a simple way to return to the homepage.

This project was created as part of **Day 30 of my Web Development Internship**.

## Project Preview

The page follows a clean, minimal design with a warm background, green and coral colors, and a small map illustration. The layout is responsive and works on both desktop and mobile screens.

## How It Works

When a visitor opens a page that is unavailable, a 404 page provides a clear explanation instead of leaving them confused.

This project includes a friendly message and a map-inspired illustration to make the error feel less frustrating. The homepage button helps visitors return to the main page, while the back link allows them to return to their previous location.

The illustration is created using HTML and CSS rather than an external image.
